Full Description:
FORGE is a professional security scanning platform for penetration testers and security engineers. Scan web applications, Linux hosts via SSH, and codebases for vulnerabilities using AI-powered agents.

Features:
• Web vulnerability scanning with AI agent swarm
• OS security scanning via SSH (privilege escalation, misconfigurations, CVEs)
• Codebase scanning from GitHub URLs or ZIP uploads
• Real-time live feed of agent activity during scans
• Chain discovery — multi-step attack path visualization
• PDF report export
• Multi-organization support with role-based access
