## Task 3: LLM Latency Tracking — 🔀 REDIRECTED (built reporting layer instead of redundant column)

**Status (2026-05-31): DONE, with a scope change from the original plan.**

**What changed and why:** During execution we found the planned `latency_ms` column was redundant — `LLMUsageEvent` already has a `duration_ms` column (`backend/app/models/llm_usage.py:24`), populated by `TrackedLLM.ainvoke()` which captures `t0 = time.monotonic()` immediately before the LLM call (after budget/rate-limit/compression) and writes `duration_ms=int((time.monotonic() - t0) * 1000)` via `_log_usage` (`backend/app/brain/llm_factory.py:684,697`). That is exactly the pure LLM round-trip latency the new column would have held. Adding `latency_ms` would have duplicated it.

So Task 3 was **redirected** to deliver the task's real intent — *surfacing* p50/p95 latency and token distribution — rather than its literal mechanism. As implemented (commit `5d5f224`):
- **`backend/app/brain/usage_stats.py`** (new) — pure, portable aggregation: `_percentile()` (nearest-rank, computed in Python so it works on Postgres AND MySQL), `_dist()`, and `aggregate_latency_stats(rows)` which groups by task type and returns per-task `calls`, `latency_ms` {avg,p50,p95,min,max}, and `input_tokens`/`output_tokens` {avg,p50,p95}.
- **`GET /api/v1/org/llm/latency-stats`** (added to `backend/app/api/org_llm.py`) — org-scoped, optional ISO `since` filter (400 on bad input), returns `{"tasks": [...], "total_calls": N}`. Reads the existing `duration_ms`; no schema change.
- Tests: `backend/tests/test_usage_stats.py` (6 unit) + `backend/tests/test_latency_stats_endpoint.py` (3 API), all passing.

**No `latency_ms` column and no migration were added.**

Accepted minor trade-offs (from code review): the endpoint fetches matching rows and aggregates in Python (deliberate, for DB portability; bounded by org-scope + `since`), and the per-call token-distribution keys (`input_tokens`/`output_tokens`) intentionally differ in meaning from the summed totals in the sibling `/usage` endpoint (disambiguated by their nested `{avg,p50,p95}` shape).

**Original purpose (for reference):** The `LLMUsageEvent` model already records token counts and cost. Add `latency_ms` so we can compute p50/p95 LLM call latency per task type.

  ```python
  # backend/app/api/os_rate_limit.py
  """Per-host lock: prevent concurrent SSH fingerprinting of the same host."""
  from __future__ import annotations
  import asyncio
  from contextlib import asynccontextmanager


  class FingerprintAlreadyRunningError(Exception):
      """Raised when a fingerprint scan is already running for the given host."""
      def __init__(self, host: str):
          super().__init__(f"A fingerprint scan is already running for host: {host}")
          self.host = host


  class FingerprintLock:
      """In-process async lock keyed by host string."""

      def __init__(self) -> None:
          self._locks: dict[str, asyncio.Lock] = {}
          self._meta: dict[str, asyncio.Lock] = {}
          self._guard = asyncio.Lock()

      @asynccontextmanager
      async def acquire(self, host: str):
          async with self._guard:
              if host not in self._locks:
                  self._locks[host] = asyncio.Lock()
          lock = self._locks[host]
          if lock.locked():
              raise FingerprintAlreadyRunningError(host)
          async with lock:
              yield
          # Clean up stale lock entries to avoid unbounded growth
          async with self._guard:
              if host in self._locks and not self._locks[host].locked():
                  del self._locks[host]


  # Module-level singleton shared across all pipeline coroutines in this worker process.
  _fingerprint_lock = FingerprintLock()
  ```

  ```python
  # backend/app/swarm/agents/binary_agent.py
  """BinaryAnalysisAgent — static analysis of ELF/PE/Mach-O binaries.

  Tier 1 (always): POSIX tools (file, nm, objdump, strings) — no external deps.
  Tier 2 (optional): LLM synthesis of raw symbol + string analysis output.
  """
  from __future__ import annotations

  import asyncio
  import logging
  import re
  from dataclasses import dataclass
  from pathlib import Path

  from langchain_core.messages import HumanMessage, SystemMessage

  from app.brain.llm_factory import TaskType, get_llm
  from app.swarm.agents.base import BaseAgent
  from app.ws import progress as ws_progress

  logger = logging.getLogger(__name__)


  # Dangerous libc symbols that indicate memory-unsafe patterns
  _DANGEROUS_SYMBOLS = {
      "strcpy":   ("buffer_overflow_risk", "high",    "strcpy() has no bounds checking; use strncpy() or strlcpy()"),
      "strcat":   ("buffer_overflow_risk", "medium",  "strcat() has no bounds checking; use strncat()"),
      "gets":     ("buffer_overflow_risk", "critical","gets() is unconditionally unsafe; use fgets()"),
      "sprintf":  ("format_string_risk",   "medium",  "sprintf() without format bounds; use snprintf()"),
      "system":   ("command_injection_risk","high",   "system() passes input to shell; prefer execve()"),
      "popen":    ("command_injection_risk","medium", "popen() passes input to shell"),
      "scanf":    ("buffer_overflow_risk", "medium",  "scanf() with %s is unsafe; use width specifiers"),
  }

  # Regex patterns for hardcoded secrets in strings output
  _SECRET_PATTERNS = [
      (re.compile(r"(?i)password\s*[=:]\s*\S+"), "hardcoded_password", "high"),
      (re.compile(r"(?i)api[_-]?key\s*[=:]\s*\S{8,}"), "hardcoded_api_key", "high"),
      (re.compile(r"(?i)secret\s*[=:]\s*\S{8,}"), "hardcoded_secret", "high"),
      (re.compile(r"BEGIN (RSA|EC|OPENSSH|PGP) PRIVATE KEY"), "embedded_private_key", "critical"),
      (re.compile(r"(?i)aws_access_key_id\s*[=:]\s*\S{16,}"), "hardcoded_aws_key", "critical"),
  ]


  def _parse_file_type(file_output: str) -> dict:
      """Extract binary type and SUID status from `file` command output."""
      result = {"binary_type": "unknown", "has_suid": False, "arch": "unknown"}
      if "ELF" in file_output:
          result["binary_type"] = "ELF"
          m = re.search(r"(\d{2}-bit)", file_output)
          if m:
              result["arch"] = m.group(1)
      elif "PE32" in file_output or "PE64" in file_output:
          result["binary_type"] = "PE"
      elif "Mach-O" in file_output:
          result["binary_type"] = "Mach-O"
      if "setuid" in file_output.lower():
          result["has_suid"] = True
      return result


  def _scan_symbols(nm_output: str) -> list[dict]:
      """Return findings for dangerous undefined symbols in nm output."""
      findings = []
      for line in nm_output.splitlines():
          parts = line.split()
          if len(parts) < 2:
              continue
          # Undefined externals (imported from libc) are flagged 'U'
          if parts[-2] == "U":
              sym = parts[-1].lstrip("_")  # strip leading underscore (macOS)
              if sym in _DANGEROUS_SYMBOLS:
                  vuln_type, severity, desc = _DANGEROUS_SYMBOLS[sym]
                  findings.append({
                      "vulnerability": f"dangerous_symbol_{sym}",
                      "vulnerability_class": vuln_type,
                      "severity": severity,
                      "description": f"Binary imports {sym}(): {desc}",
                      "evidence": line.strip(),
                      "recommendation": desc,
                      "confidence_score": 0.85,
                      "chain_potential": severity in ("critical", "high"),
                  })
      return findings


  def _scan_strings(strings_output: str) -> list[dict]:
      """Return findings for hardcoded secrets found in strings output."""
      findings = []
      for line in strings_output.splitlines():
          for pattern, vuln_type, severity in _SECRET_PATTERNS:
              if pattern.search(line):
                  findings.append({
                      "vulnerability": vuln_type,
                      "vulnerability_class": "hardcoded_secret",
                      "severity": severity,
                      "description": f"Hardcoded credential detected in binary strings",
                      "evidence": line[:200],  # cap to avoid huge findings
                      "recommendation": "Remove hardcoded credentials; use environment variables or a secrets manager",
                      "confidence_score": 0.75,
                      "chain_potential": False,
                  })
                  break  # one finding per line
      return findings


  async def _run_cmd(cmd: list[str], timeout: float = 30.0) -> str:
      """Run a subprocess command; return stdout or empty string on failure."""
      try:
          proc = await asyncio.create_subprocess_exec(
              *cmd,
              stdout=asyncio.subprocess.PIPE,
              stderr=asyncio.subprocess.DEVNULL,
          )
          stdout, _ = await asyncio.wait_for(proc.communicate(), timeout=timeout)
          return stdout.decode(errors="replace")
      except Exception as e:
          logger.debug("Binary agent cmd failed %s: %s", cmd[0], e)
          return ""


  @dataclass
  class BinaryAnalysisAgent(BaseAgent):

      async def _execute(self, task: dict) -> dict:
          target_path = task.get("target_path", "")
          org_id = task.get("org_id")

          if not target_path or not Path(target_path).exists():
              await ws_progress.progress(
                  self.engagement_id, "binary_analysis.skipped",
                  f"target_path not found: {target_path}",
              )
              return {"agent_type": self.agent_type, "findings": []}

          await ws_progress.progress(
              self.engagement_id, "binary_analysis.started",
              f"Analyzing binary: {target_path}",
          )

          findings: list[dict] = []

          # 1. file — determine binary type
          file_out = await _run_cmd(["file", target_path])
          file_info = _parse_file_type(file_out)

          if file_info["has_suid"]:
              findings.append({
                  "vulnerability": "suid_binary",
                  "vulnerability_class": "privilege_escalation_risk",
                  "severity": "high",
                  "description": f"Binary has SUID bit set: {target_path}",
                  "evidence": file_out.strip(),
                  "recommendation": "Remove SUID bit unless explicitly required; audit the binary for exploitable behaviors",
                  "confidence_score": 0.95,
                  "chain_potential": True,
              })

          # 2. nm — dangerous symbol imports
          nm_out = await _run_cmd(["nm", "-D", target_path])
          if not nm_out:
              nm_out = await _run_cmd(["nm", target_path])
          findings.extend(_scan_symbols(nm_out))

          # 3. strings — hardcoded credentials
          strings_out = await _run_cmd(["strings", target_path])
          findings.extend(_scan_strings(strings_out))

          # 4. LLM synthesis for context (best-effort, skipped if LLM unavailable)
          if findings:
              try:
                  llm = await get_llm(TaskType.binary_analysis, org_id=org_id)
                  summary_prompt = (
                      f"Binary: {target_path}\n"
                      f"Type: {file_info['binary_type']} {file_info.get('arch', '')}\n"
                      f"Dangerous symbols: {[f['vulnerability'] for f in findings if 'symbol' in f['vulnerability']]}\n"
                      f"Findings count: {len(findings)}\n\n"
                      "Summarize the security risk and suggest 2-3 additional manual analysis steps "
                      "a pentester should take for this binary. Reply in 3 sentences max."
                  )
                  resp = await llm.ainvoke([
                      SystemMessage(content="You are a binary exploitation expert."),
                      HumanMessage(content=summary_prompt),
                  ])
                  if findings:
                      findings[0]["llm_summary"] = resp.content[:500]
              except Exception:
                  logger.debug("BinaryAnalysisAgent: LLM synthesis skipped")

          await ws_progress.progress(
              self.engagement_id, "binary_analysis.complete",
              f"Binary analysis complete — {len(findings)} findings",
          )
          self.signal_history.append(1.0 if findings else 0.5)
          return {
              "agent_type": self.agent_type,
              "findings": findings,
              "binary_type": file_info["binary_type"],
          }
  ```
